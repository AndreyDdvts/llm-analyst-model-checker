### P1 — «Отменённая заявка не должна быть исполнена»: PROPERTY_HOLDS
Свойство не нарушено в исследованной конечной модели при заданных ограничениях. Это не доказательство корректности production-системы.

Связанные требования: R3: «Отменённая заявка не должна быть исполнена.»

### P3 — «Заявку вообще можно исполнить»: PROPERTY_HOLDS
Целевое состояние достижимо, например так:
1. Начальное состояние: status=Created, approved=false, cancelled=false.
2. Заявка согласована [Approve]. Изменения: status: Created → Approved; approved: false → true.
3. Система исполняет заявку [Execute]. Изменения: status: Approved → Executed. Сохранились: approved=true (Признак согласования).

Связанные требования: R1: «Заявка после согласования может быть исполнена.»
